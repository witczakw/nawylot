# Ograniczenia — dlaczego NIE robimy auto-zakupu

1. **Prawo turystyczne (PL).** Sprzedaż lotu + noclegu na ten sam wyjazd może być imprezą
   turystyczną lub powiązanymi usługami turystycznymi → wpis do rejestru marszałka,
   zabezpieczenie finansowe (gwarancja/ubezpieczenie), składki na TFG.
2. **Pieniądze klientów.** Przyjmowanie „budżetu” do wydania później może zahaczać
   o usługi płatnicze (KNF). Do sprawdzenia z prawnikiem, jeśli kiedykolwiek wrócimy do tematu.
3. **Płatności kartą bez udziału klienta** — wymogi silnego uwierzytelnienia (PSD2).
4. **Rynek.** OpenAI wycofało checkout z ChatGPT (III 2026) — użytkownicy chcą, żeby AI
   szukało, ale kupują sami. Nasz model: agent pilnuje, człowiek klika.

5. **Stripe tylko za naszą usługę.** Płatność za dostęp do alertów to zwykła usługa cyfrowa. Pobieranie pieniędzy za podróż zmieniłoby status firmy (pkt 1–2).

Zmiana którejkolwiek zasady z CLAUDE.md wymaga decyzji całego zespołu i wpisu tutaj.
